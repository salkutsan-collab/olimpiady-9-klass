# Петербургский олимпиадный сезон

Справочник по школьным олимпиадам для 9 класса: математика, физика, обществознание и инженерные направления. Отобраны только олимпиады с подтвержденной очной площадкой в Санкт-Петербурге.

## Доступ

Страница закрыта паролем. Содержимое зашифровано в браузере: AES-256-GCM, ключ выводится из логина и пароля через PBKDF2-SHA256 (250 000 итераций). В репозитории и в исходном коде страницы лежат только зашифрованные данные - без верного пароля текст прочитать нельзя.

Логин и пароль сообщаются отдельно и в репозиторий не попадают.

## Что внутри

- `index.html` - самодостаточная страница: форма входа и зашифрованный справочник. Внешних файлов нет, кроме шрифтов Google Fonts.

Расшифровка работает только в защищенном контексте (https или `http://localhost`) - это требование браузерного API `crypto.subtle`.

## Как пересобрать

Страница генерируется из исходного HTML скриптом на Node.js: он шифрует справочник выбранным логином и паролем и вкладывает результат в шаблон. Скрипт сборки и незашифрованный исходник в репозиторий не входят и лежат в рабочей папке проекта.
